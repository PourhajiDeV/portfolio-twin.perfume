# 🌸 Twin Perfumes - Avant-Garde Niche Perfumery

گالری عطر تویین، یک تجربه وب ژورنالی (Editorial Design) و آوانگارد است که برای نمایش محصولات لوکس و عطرهای نیش (Niche) طراحی شده است. استفاده از هدر Center-Split و پالت رنگی بنفش آلوچه‌ای، این پروژه را به یک پورتفولیوی سطح جهانی تبدیل کرده است.

## ✨ ویژگی‌های کلیدی (Features)

- **طراحی ژورنالی (Editorial):** تمرکز بر روی فضای سفید، تایپوگرافی‌های بسیار بزرگ (Oversized Typography) و چیدمان نامتقارن.
- **هدر Center-Split:** طراحی خاص هدر با قرارگیری لوگو در مرکز و تقسیم منوها به دو بال چپ و راست.
- **افکت‌های تعاملی پیشرفته:** نشانگر ماوس اختصاصی (Custom Magnetic Cursor) و انیمیشن‌های Reveal برای تصاویر.
- **کارت‌های محصول شناور:** طراحی سه‌بعدی و شناور کارت‌های محصولات و باکس‌های هدیه با سایه‌های عمیق.

## 🛠 تکنولوژی‌های استفاده شده (Tech Stack)

- **HTML5**
- **CSS3** (Backdrop-filter, Custom Cursors, Mix-blend-mode)
- **Vanilla JavaScript** (Cursor tracking, DOM Events)
- **GSAP (GreenSock)** (Advanced Timelines & Scroll Control)

## 🚀 نحوه اجرا (How to Run)

برای مشاهده پروژه، تنها کافیست فایل `index.html` را باز کنید. پیشنهاد می‌شود برای تجربه بهتر افکت‌های نشانگر ماوس، پروژه را در نسخه دسکتاپ مشاهده نمایید.
